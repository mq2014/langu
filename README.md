# 览古 · langu

一个以「锦江十二月市」为主题的历史学习 + PK 对战网页（MVP）。

由《AI创造说明书》《AI灵感卡》两份设计稿驱动，按设计说明书末尾的「创造指令」实现为纯前端单文件网站。

## 功能

- **学习板块 · 锦江十二月市**：12 个月主题市集（正月灯市 → 十二月桃符市），每个市集含
  - 历史故事点
  - 锦江打卡点
  - 年轻互动点
  - 每一点均可点击查看详情
- **市集趣答**：十二月市 / 锦江相关选择题小测
- **锦江岁时志**：锦江文化讲解
- **PK 对战**：单人（对战机器人）/ 双人（两人同屏抢答）两种模式，答对先手选「回血 +10 / 攻击 -10」，血量归零判负，段位 青铜→王者
- **注册 / 账号**：名称 + 密码（存 localStorage），未注册不能进 PK
- **左拉 AI 导游**：右下角悬浮，随页面给引导并支持关键词问答

## 运行

直接用浏览器打开 `index.html` 即可（单文件、零外部依赖）；
或本地起静态服务：`python -m http.server` 后访问。

## 说明

账号密码以明文存于浏览器 localStorage，仅适合本地演示 / 比赛用途。
